# XAI Reliability Evaluation Framework: Measuring Trustworthiness of LIME and SHAP Explanations

## 📌 Project Overview

This project presents a comprehensive framework for evaluating the reliability, robustness, and trustworthiness of Explainable AI (XAI) explanations generated by **LIME** and **SHAP**.

Although XAI techniques help explain model predictions, they often fail to indicate whether those explanations are reliable. This project addresses that challenge by measuring explanation stability under various perturbations and introducing a novel reliability assessment framework.

The framework is validated across multiple domains, including activity recognition, EEG signal analysis, electricity load forecasting, and image classification.

---

## 🎯 Objectives

- Evaluate consistency of explanations across different XAI methods.
- Measure robustness of explanations under perturbations.
- Compare feature importance agreement between LIME and SHAP.
- Identify misleading or unreliable explanations.
- Quantify explanation reliability using custom metrics.
- Provide statistical validation of explanation trustworthiness.

### ✅ Explainability Methods

#### LIME (Local Interpretable Model-Agnostic Explanations)

Provides local explanations for individual predictions.

#### SHAP (SHapley Additive exPlanations)

Provides feature attribution scores based on cooperative game theory.

---

### ✅ Perturbation-Based Reliability Testing

The framework evaluates explanation stability under:

- Gaussian Noise Injection
- Missing Value Injection
- Distribution Shift
- Feature Corruption / Feature Swapping

---

### ✅ Explanation Reliability Index (ERI)

Custom reliability metrics introduced in this project:

| Metric | Description |
|----------|-------------|
| ERI-S | Stability under perturbations |
| ERI-R | Robustness against redundancy |
| ERI-T | Temporal consistency |
| ERI-C | Cross-method consistency |

---

### ✅ Four-Case Reliability Decision Framework

Each explanation is categorized into one of four reliability cases:

| Category | Interpretation |
|------------|---------------|
| RELIABLE | Prediction and explanation remain stable |
| MISLEADING | Prediction stable but explanation changes |
| DANGEROUS | Prediction changes but explanation remains stable |
| NORMAL_DRIFT | Both prediction and explanation change |

---

### ✅ Statistical Validation

The framework incorporates:

- Multi-seed experiments
- Bootstrap confidence intervals
- Precision, Recall, and F1-score analysis
- Reliability distribution analysis
- Cross-method agreement statistics
